# Contributing Guide

## Branch naming

```text
feature/<your-name>-<task>
```

Examples:

- `feature/ahmed-greeting`
- `feature/sara-calculator`
- `feature/omar-team-info`

## Commit message style

```text
type: short description
```

Examples:

- `feat: add greeting message`
- `feat: add multiply method`
- `docs: update team info`
- `fix: correct division by zero handling`

## Workflow

1. Create a feature branch from `main`
2. Make your changes
3. Commit with a clear message
4. Push your branch
5. Open a Pull Request to `main`
6. Wait for review
7. Resolve conflicts if requested
8. Merge after approval
