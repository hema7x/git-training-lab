# Git Training Lab

Hands-on Git workflow training for interns.

## Goal

Practice a real company Git workflow:

Fork → Clone → Branch → Commit → Push → Pull Request → Merge → Resolve Conflicts

## Team

See `team.txt`

## How to run

1. Open the project in IntelliJ IDEA
2. Open `src/main/java/com/training/App.java`
3. Run the `main` method

## Project structure

```text
git-training-lab/
├── README.md
├── team.txt
├── docs/
│   └── CONTRIBUTING.md
└── src/main/java/com/training/
    ├── App.java
    └── Calculator.java
```

## Rules

1. Never push directly to `main`
2. Always work on a feature branch
3. Always open a Pull Request
4. Pull before you push if `main` changed
